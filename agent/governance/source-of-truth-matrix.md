## 补充说明

- 仓内 extension 通过已登记的正式 profile、有效自动发现 profile 或仓内合同 service 的显式 `--config-path` 接入；profile registry 不允许用非合同路径为 service 增加别名，仓外非标准 extension manifest 不属于正式入口。
- 显式登记与自动发现的默认扩展 profile 必须启用 `agent_platform`、自身扩展和递归 required dependencies；optional dependencies 不进入默认启用集合。manifest 目录仅覆盖平台、required dependencies 和自身。扩展贡献的 registry 与 surface 真源保留在 owner 根目录内；可见 manifest 与索引采用严格字段合同。完整规则见 [扩展挂载指南](../../docs/architecture/explicit-extension-packages.md)。
- 所有模板、脚手架、doctor 与 guard 都必须以上述真源矩阵为准。
